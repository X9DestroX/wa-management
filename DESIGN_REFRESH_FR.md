# Refonte visuelle v1.7.8

Cette mise à jour est une refonte CSS seulement. Elle vise une interface d’entreprise plus soignée avec une palette claire : bleu marine, bleu et accents or discrets.

Éléments visuels concernés : navigation latérale, état actif, champs de saisie, boutons, cartes KPI, panneaux, tableaux, modales, page de connexion, états focus clavier et petits écrans.

Aucun identifiant DOM, nom de fonction JavaScript, endpoint API, schéma SQL, logique de prix, gestion de stock, permissions ou flux d’authentification n’est modifié.
